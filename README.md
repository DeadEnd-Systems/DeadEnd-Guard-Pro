## ⚙️ Under The Hood: The Custom Execution Engine

*Developed by DeadEnd Systems*

📌 **The Problem:** Most free or budget hosting platforms (like PythonAnywhere) aggressively kill background threads (`threading.Timer`). This makes it impossible to run auto-delete tasks, mutes, or 'Ghost Bombs' reliably for Telegram moderation bots.
